# הודעת usage וקודי יציאה

סקריפטים טובים מסבירים איך להשתמש בהם. כתבו את `~/usage.sh`:

1. בלי ארגומנט הוא מדפיס את השורה `Usage: usage.sh NAME` לפלט הרגיל, ומסתיים בקוד יציאה `1`.
2. עם ארגומנט אחד הוא מסתיים בקוד יציאה `0`.
3. הפכו את הסקריפט לניתן להרצה, והתחילו אותו בשורה `#!/bin/bash`.

אחרי שמריצים, `echo $?` מראה את קוד היציאה של הסקריפט.

רמז: `$#` הוא מספר הארגומנטים. `[ $# -eq 0 ]` נכון כשאין אף ארגומנט, ו-`exit 1` מסיים את הסקריפט עם קוד 1.
