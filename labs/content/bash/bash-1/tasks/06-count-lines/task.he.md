# סופרים שורות בקובץ עם while read

כתבו סקריפט `~/count_lines.sh` שסופר את השורות של הקובץ שנותנים לו. השתמשו בלולאת `while read`.

1. `~/count_lines.sh FILE` מדפיס את מספר השורות ב-FILE, ורק את המספר.
2. גם שורה אחרונה שאין בסופה תו שורה חדשה נספרת כשורה.
3. קובץ ריק נותן `0`, וגם שורות ריקות נספרות.
4. הפכו את הסקריפט לניתן להרצה, והתחילו אותו בשורה `#!/bin/bash`.

כדי לנסות, ה-setup יצר את `~/data/fruits.txt`. בשורה האחרונה שלו אין תו שורה חדשה, ולכן התשובה הנכונה עבורו היא `5`.

רמז: `while read -r line; do ...; done < "$1"` מריץ את הגוף פעם אחת לכל שורה בקובץ. `n=$((n + 1))` מוסיף אחד למשתנה. זכרו ש-`read` מוותר על שורה אחרונה שאין בסופה תו שורה חדשה.
