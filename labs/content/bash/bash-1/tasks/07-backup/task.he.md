# סקריפט גיבוי

כתבו סקריפט `~/backup.sh` שמגבה את התיקייה `~/notes`.

1. הרצה של `~/backup.sh` יוצרת את הארכיון הדחוס `~/backup.tar.gz` של התיקייה `~/notes`, עם כל מה שיש בה.
2. השמות בתוך הארכיון מתחילים ב-`notes/` ולא ב-`/home/student`.
3. בהרצה נוספת הסקריפט מחליף את הארכיון בחדש, כך שקובץ שמחקתם מ-`~/notes` נעלם גם מהארכיון.
4. הפכו את הסקריפט לניתן להרצה.

אפשר להציץ לתוך ארכיון עם `tar tzf ~/backup.tar.gz`.

רמז: `tar -czf archive.tar.gz folder` יוצרת ארכיון דחוס (`c` יצירה, `z` דחיסת gzip, `f` שם הקובץ). `tar -C ~ ...` עוברת קודם לתיקיית הבית, וכך השמות בפנים יכולים להתחיל ב-`notes/`.
