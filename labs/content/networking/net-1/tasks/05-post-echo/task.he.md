# שולחים בקשת POST

עד עכשיו ביקשתם רק דפים (GET). בקשת POST שולחת מידע אל השרת. על המחשב שלכם רץ שירות echo קטן, בכתובת `127.0.0.1:9090/echo`. הוא עונה באובייקט JSON שמכיל את הגוף ששלחתם, ו-`id` של השירות.

שלחו לו את גוף ה-JSON הזה, עם הכותרת `Content-Type: application/json`:

```
{"lab":"net-1","msg":"hello"}
```

שמרו את התשובה של השירות בקובץ `reply.json` בתיקיית הבית שלכם.

רמז: `curl -X POST -H 'Header: value' -d 'body' URL`. הכתובת היא `http://127.0.0.1:9090/echo`. אם השירות עונה עם שגיאה, בדקו את הכותרת.
