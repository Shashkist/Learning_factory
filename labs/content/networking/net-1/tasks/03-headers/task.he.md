# כותרות תשובה

חוץ מהדף עצמו, שרת אינטרנט שולח כותרות (headers): שורות כמו הסטטוס וסוג התוכן. השרת של `~/site` רץ בפורט `8080`.

שמרו את כותרות התשובה של דף הבית `/` בקובץ `headers.txt` בתיקיית הבית שלכם. בקובץ צריכות להיות רק הכותרות (מתחילות בשורת הסטטוס), בלי הדף עצמו.

רמז: `curl -I URL` מבקשת רק את הכותרות. הכתובת נראית כמו `http://127.0.0.1:8080/`. את הפלט שולחים לקובץ עם `>`.
