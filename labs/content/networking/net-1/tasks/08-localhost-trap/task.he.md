# שואלים את השירות

על המחשב שלכם רץ שירות קטן בכתובת `127.0.0.1`, בפורט `9091`. כשמבקשים ממנו את הדף שלו, הוא עונה בשורה אחת.

שאלו אותו עם `curl` ושמרו את התשובה בקובץ `pong.txt` בתיקיית הבית שלכם, בדיוק כפי שהשירות שלח אותה.

רמז: `curl http://127.0.0.1:9091/` מדפיסה את התשובה. את הפלט שולחים לקובץ עם `>`.
