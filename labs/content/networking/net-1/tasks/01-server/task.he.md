# מפעילים שרת אינטרנט

שרת אינטרנט הוא תוכנה שממתינה לבקשות ועונה עליהן עם קבצים. ל-Python יש שרת קטן מובנה.

בתיקייה `~/site` יש אתר קטן (`index.html`, `data.json` ועוד). הפעילו שרת אינטרנט שמגיש את התיקייה הזאת בפורט `8080`, והשאירו אותו רץ ברקע, כדי שתוכלו להמשיך להשתמש בטרמינל.

הפקודה היא `python3 -m http.server 8080`. היא מגישה את התיקייה שאתם נמצאים בה, אז קודם נכנסים אל `~/site`. מוסיפים `&` בסוף הפקודה כדי להריץ אותה ברקע.

רמז: כדי לראות שזה עובד, מבקשים ממנו דף עם `curl http://127.0.0.1:8080/index.html`.
