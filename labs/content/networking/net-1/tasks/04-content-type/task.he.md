# סוג התוכן

הכותרת `Content-Type` אומרת ללקוח איזה סוג מידע חזר. השרת של `~/site` רץ בפורט `8080`.

מצאו מהו סוג התוכן של הדף `/data.json` ושמרו אותו בקובץ `content-type.txt` בתיקיית הבית שלכם. כתבו רק את הערך (החלק שאחרי `Content-Type:`), לא את כל שורת הכותרת.

רמז: קוראים את הכותרות עם `curl -I URL`, למשל `curl -I http://127.0.0.1:8080/data.json`, ולוקחים את הערך מתוך השורה. אפשר גם לבקש מ-`curl` להדפיס רק את הערך עם `-w '%{content_type}'`.
