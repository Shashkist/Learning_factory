# פתרון

```bash
ip addr
ip -4 -o addr show scope global | awk '{print $4}' > ~/myip.txt
cat ~/myip.txt
```

הפקודה `ip addr` מציגה את כרטיסי הרשת. שורת ה-`inet` של הכרטיס שאינו `lo` נראית כך: `inet 172.20.0.5/16 brd ... scope global eth0`. הכתובת היא המילה השנייה, `172.20.0.5/16`: המספר `172.20.0.5` הוא הכתובת, ו-`/16` אומר ש-16 הביטים הראשונים הם החלק של הרשת. אפשר גם להעתיק את הערך ידנית לקובץ עם `echo`. כתובת ה-loopback `127.0.0.1/8` מגיעה רק למכונה עצמה.
