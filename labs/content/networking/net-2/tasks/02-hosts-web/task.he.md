# נותנים שם לשירות מקומי

שירות web קטן רץ על המכונה הזאת, בפורט `8081`. אפשר להגיע אליו לפי כתובת: `curl http://127.0.0.1:8081/`. עכשיו תנו לו שם, כמו ש-DNS עושה לאתר אמיתי.

1. גרמו לשם `web.lab` להצביע על `127.0.0.1` בקובץ `/etc/hosts`. שורה בקובץ הזה היא כתובת ואחריה שם אחד או יותר.
2. הביאו את הדף של השירות לפי השם שלו, עם `curl -s http://web.lab:8081/`, ושמרו אותו ב-`~/web-reply.txt`.

בדקו את עצמכם: `getent hosts web.lab` חייב להחזיר `127.0.0.1`.

רמז: אם פקודה מחזירה שגיאה, קראו את ההודעה. היא אומרת מה לא בסדר.
