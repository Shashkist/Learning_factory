# מפעילים תהליך ושומרים את ה-PID שלו

1. הפעילו `sleep 600` ברקע, כדי לשמור על ה-prompt.
2. מצאו את ה-PID (מזהה התהליך) של ה-`sleep` הזה.
3. כתבו את ה-PID, ורק אותו, לקובץ `~/sleep.pid`.

בדקו בעצמכם: `cat ~/sleep.pid` מדפיס מספר, ו-`ps -p "$(cat ~/sleep.pid)"` מציג את `sleep`.

רמז: סיום פקודה ב-`&` מריץ אותה ברקע. ה-shell שומר את ה-PID של הפקודה האחרונה שרצה ברקע במשתנה `$!`. אפשר גם למצוא אותו עם `pgrep -x sleep`.
