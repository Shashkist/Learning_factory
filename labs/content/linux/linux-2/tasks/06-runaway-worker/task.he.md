# עוצרים תהליך שיצא משליטה

תהליך בשם `runaway-worker` רץ ושורף את המכונה בלי סיבה. לידו רץ תהליך תקין בשם `runaway-worker-keep`, שהצוות עדיין צריך.

1. מצאו את `runaway-worker` ועצרו אותו.
2. השאירו את `runaway-worker-keep` רץ.

שני התהליכים שייכים ל-`root`, ולכן צריך `sudo`. צפו בהם עם `ps aux | grep runaway` או `pgrep -a runaway`, ובדקו שוב אחרי שעצרתם אחד.

רמז: אפשר לעצור תהליך לפי ה-PID שלו (`kill`) או לפי השם שלו (`pkill`). זהירות: שם מותאם כתבנית, ואחד השמות מוכל בשני.
