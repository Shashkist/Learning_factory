# יוצרים משתמש

מפתח חדש מצטרף לצוות. צרו לו חשבון.

1. שם המשתמש הוא `dev1`.
2. יש לו תיקיית בית, `/home/dev1`.
3. ה-shell שלו הוא `/bin/bash`.

בדקו את התוצאה עם `getent passwd dev1`: שני השדות האחרונים הם תיקיית הבית וה-shell.

רמז: ל-`useradd` יש אפשרות לתיקיית בית ואפשרות ל-shell. קראו `man useradd`. לחשבון שלכם יש `sudo`, אז כתבו אותו לפני פקודות שדורשות root.
