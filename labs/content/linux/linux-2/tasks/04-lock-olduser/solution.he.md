# פתרון

```bash
sudo passwd -l olduser
sudo passwd -S olduser
```

`passwd -l` מוסיף `!` לפני ה-hash של הסיסמה, ולכן שום סיסמה כבר לא מתאימה, והחשבון והקבצים נשארים. גם `sudo usermod -L olduser` עושה את אותו דבר. עכשיו `passwd -S` מציג `L`. שינוי ה-shell או מחיקת המשתמש הם לא אותו דבר: הראשון משאיר את הסיסמה שמישה, והשני מוחק את החשבון.
