# פתרון

```bash
chmod +x ~/backup.sh
crontab -e
```

הוסיפו בעורך את השורה הזאת, שמרו וצאו:

```
*/5 * * * * ~/backup.sh
```

ואז בדקו:

```bash
crontab -l
ls -l ~/backup.sh
```

חמשת השדות הם דקה, שעה, יום בחודש, חודש ויום בשבוע. `*/5` בשדה הדקות אומר כל 5 דקות. בלי `chmod +x` ל-cron אין דרך להריץ את הסקריפט. `0 * * * *` היה מריץ אותו פעם בשעה, ו-`* * * * *` כל דקה.
