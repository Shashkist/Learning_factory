# Build a folder tree

You are starting a small website project. Make this structure inside your home folder:

```text
projects/
  website/
    css/
    images/
```

The folder `projects` is already there. Use `mkdir` to create the rest.

Hint: `mkdir -p` creates the missing folders on the way, so one command can build a whole path. Use `ls` and `pwd` to see where you are.
