# בונים עץ תיקיות

אתם מתחילים פרויקט קטן של אתר. צרו בתיקיית הבית שלכם את המבנה הבא:

```text
projects/
  website/
    css/
    images/
```

התיקייה `projects` כבר קיימת. את השאר יוצרים עם `mkdir`.

רמז: הדגל `-p` של `mkdir` יוצר גם תיקיות ביניים שחסרות, כך שפקודה אחת יכולה לבנות נתיב שלם. עם `ls` ו-`pwd` אפשר לראות איפה אתם נמצאים.
