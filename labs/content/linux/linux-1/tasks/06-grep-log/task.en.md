# Search a log

The file `~/logs/app.log` is the log of a small program. Most lines are fine, but some say `ERROR`.

Save only the lines that contain `ERROR` in a new file, `~/errors.txt`. Do not change the log itself.

Hint: first look at the log with `cat` or `less`. Then `grep` prints only the lines that match a word. Send its output to a file with `>`.
