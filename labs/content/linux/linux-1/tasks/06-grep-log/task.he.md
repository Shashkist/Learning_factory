# מחפשים בלוג

הקובץ `~/logs/app.log` הוא הלוג של תוכנה קטנה. רוב השורות תקינות, אבל בחלקן כתוב `ERROR`.

שמרו רק את השורות שמכילות `ERROR` בקובץ חדש, `~/errors.txt`. אל תשנו את הלוג עצמו.

רמז: קודם מסתכלים על הלוג עם `cat` או `less`. אחר כך `grep` מדפיסה רק את השורות שמכילות מילה מסוימת. את הפלט שלה שולחים לקובץ עם `>`.
