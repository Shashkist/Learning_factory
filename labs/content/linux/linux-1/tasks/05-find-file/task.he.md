# מוצאים קובץ אבוד

איפשהו בתוך `~/archive` יש קובץ בשם `secret-recipe.txt`. יש הרבה תיקיות, אז לא מחפשים ביד.

מצאו אותו בעזרת פקודה, ושמרו את **הנתיב המלא** שלו (הוא מתחיל ב-`/home/student`) בקובץ בשם `~/found.txt`.

רמז: `find` מחפשת בתיקיות. נסו `find ~ -name` ואחריו שם הקובץ. את הפלט אפשר לשלוח לקובץ עם `>`.
