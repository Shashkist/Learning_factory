# Find a lost file

Somewhere inside `~/archive` there is a file called `secret-recipe.txt`. There are many folders, so do not look by hand.

Find it with a command, then save its **full path** (it starts with `/home/student`) in a file called `~/found.txt`.

Hint: `find` searches folders. Try `find ~ -name` followed by the file name. The output can be sent to a file with `>`.
