# עובר או נכשל? if ו-else

כתבו סקריפט Python בשם `~/grade.py` שמחליט אם ציון הוא ציון עובר.

1. `python3 ~/grade.py N` מדפיס `pass` כשהציון `N` הוא `60` או יותר.
2. הוא מדפיס `fail` כשהציון נמוך מ-`60`.
3. הוא מדפיס רק את המילה הזאת ומסתיים כרגיל.

נסו: `python3 ~/grade.py 75` מדפיס `pass`, ו-`python3 ~/grade.py 40` מדפיס `fail`.

רמז: המילים שמקלידים אחרי שם הסקריפט מחכות ב-`sys.argv` (אחרי `import sys`, הראשונה היא `sys.argv[1]`). הן מגיעות כטקסט, וטקסט הוא לא מספר, אז הפכו אותו למספר עם `int(...)` לפני שמשווים אותו ל-`60`.
