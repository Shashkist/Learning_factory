# מ-Celsius ל-Fahrenheit: מספרים עשרוניים

כתבו סקריפט Python בשם `~/temp.py` שממיר טמפרטורה מ-Celsius ל-Fahrenheit.

1. `python3 ~/temp.py C` מדפיס את הטמפרטורה ב-Fahrenheit: `F = C * 9 / 5 + 32`.
2. התוצאה מעוגלת לספרה עשרונית אחת ומוצגת תמיד עם ספרה עשרונית אחת.
3. `C` יכול להיות מספר שלם או מספר עם נקודה עשרונית, כמו `36.6`.

נסו: `python3 ~/temp.py 100` מדפיס `212.0`, ו-`python3 ~/temp.py 37` מדפיס `98.6`.

רמז: `round(number, 1)` מעגל לספרה עשרונית אחת, ופורמט כמו `f"{value:.1f}"` מציג בדיוק אחת. מספר עם נקודה עשרונית הוא `float`.
