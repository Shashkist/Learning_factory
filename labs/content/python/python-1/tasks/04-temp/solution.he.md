# פתרון

```bash
cat > ~/temp.py <<'EOF'
import sys

c = float(sys.argv[1])
f = c * 9 / 5 + 32
print(f"{round(f, 1):.1f}")
EOF
python3 ~/temp.py 100
python3 ~/temp.py 36.6
```

`float(...)` מקבל גם `37` וגם `36.6`, ואילו `int("36.6")` נכשל. `round(f, 1)` מעגל לספרה עשרונית אחת, ו-`:.1f` גורם לפלט להציג בדיוק אחת, ולכן `32` מודפס כ-`32.0`. בלי העיגול, מספרי floating point עלולים להדפיס זנב ארוך כמו `98.60000000000001`. משתמשים ב-`/` לחילוק: `9 // 5` הוא `1` והורס את הנוסחה.
