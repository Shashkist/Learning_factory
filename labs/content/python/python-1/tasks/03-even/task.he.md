# זוגי או אי-זוגי? השארית

כתבו סקריפט Python בשם `~/even.py` שאומר אם מספר שלם הוא זוגי או אי-זוגי.

1. `python3 ~/even.py N` מדפיס `even` כש-`N` זוגי.
2. הוא מדפיס `odd` כש-`N` אי-זוגי.
3. `0` נחשב זוגי, וגם מספרים שליליים צריכים לעבוד.

נסו: `python3 ~/even.py 10` מדפיס `even`, ו-`python3 ~/even.py 7` מדפיס `odd`.

רמז: האופרטור `%` נותן את השארית של חילוק. מספר זוגי משאיר שארית `0` כשמחלקים אותו ב-`2`.
