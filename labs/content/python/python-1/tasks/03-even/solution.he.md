# פתרון

```bash
cat > ~/even.py <<'EOF'
import sys

n = int(sys.argv[1])
if n % 2 == 0:
    print("even")
else:
    print("odd")
EOF
python3 ~/even.py 10
python3 ~/even.py -3
```

`n % 2` הוא השארית של חילוק ב-`2`: `0` למספר זוגי ו-`1` למספר אי-זוגי. ב-Python השארית של חילוק ב-`2` אף פעם לא שלילית, ולכן `-3 % 2` הוא `1` והסקריפט אומר `odd`. בודקים `== 0` ולא `== 1`, ואז הסקריפט לא צריך טיפול מיוחד במספרים שליליים.
