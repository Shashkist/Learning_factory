# Even or odd? the remainder

Write a Python script `~/even.py` that says whether a whole number is even or odd.

1. `python3 ~/even.py N` prints `even` when `N` is even.
2. It prints `odd` when `N` is odd.
3. `0` counts as even, and negative numbers work too.

Try it: `python3 ~/even.py 10` prints `even`, and `python3 ~/even.py 7` prints `odd`.

Hint: the operator `%` gives the remainder of a division. An even number leaves remainder `0` when divided by `2`.
