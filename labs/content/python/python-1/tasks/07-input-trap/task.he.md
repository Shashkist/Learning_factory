# חיבור של שני מספרים

כתבו סקריפט Python בשם `~/add.py` שמחבר שני מספרים שלמים שניתנים בשורת הפקודה.

1. `python3 ~/add.py A B` מדפיס את הסכום של `A` ו-`B`.
2. המספרים יכולים להיות שליליים או `0`.
3. הוא מדפיס רק את הסכום ומסתיים כרגיל.

נסו: `python3 ~/add.py 3 4` אמור להדפיס `7`, ו-`python3 ~/add.py -2 9` אמור להדפיס `7`.

רמז: המספר הראשון הוא `sys.argv[1]` והשני הוא `sys.argv[2]` (אחרי `import sys`). הריצו את הסקריפט וקראו מה הוא מדפיס לפני שאתם מכריזים שסיימתם.
