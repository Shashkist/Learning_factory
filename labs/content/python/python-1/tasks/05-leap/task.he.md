# שנה מעוברת: תנאים שתלויים זה בזה

כתבו סקריפט Python בשם `~/leap.py` שאומר אם שנה היא שנה מעוברת.

1. `python3 ~/leap.py YEAR` מדפיס `leap` לשנה מעוברת ו-`not leap` לכל שנה אחרת.
2. שנה שמתחלקת ב-`4` היא שנה מעוברת, חוץ משנים שמתחלקות ב-`100` (כמו `1900`) ואינן מתחלקות ב-`400`.
3. לכן `1900` היא לא שנה מעוברת, אבל `2000` כן.

נסו: `python3 ~/leap.py 2024` מדפיס `leap`, ו-`python3 ~/leap.py 2023` מדפיס `not leap`.

רמז: `and`, `or` ו-`elif` מאפשרים לשלב תנאים. החליטו איזה כלל בודקים קודם: את היוצאים מן הכלל או את המקרה הכללי.
